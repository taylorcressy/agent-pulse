# Troubleshooting

- **Unverified CLI** means discovery found a candidate outside the supported installer paths or version signature. Check its identity and location.
- **Detected with history missing** can occur before any local interaction or if an alternate profile is outside the disclosed root. Check **Connections** and your provider root override.
- **Claude allowance needs integration** means the collector needs a status-line observation. Enable it in **Connections** and use Claude normally. A supported account sends allowance after an API response.
- **Refresh due** means a reported reset timestamp passed. A later provider observation will replace it.
- **Pairing code expired** means the companion rotated its code. Read the current contents of the pairing-code file and enter them once.
- **Port already in use** means another process owns port 43129. AgentPulse shares a verified existing companion with the desktop. Free the port if a different service owns it.
- **WSL or chroot requires a collector** means the environment has no registered feed. Follow the [helper setup](discovery.md).
